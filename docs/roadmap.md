# 迭代路线

首个 PR 只建立可测试的骨架和基本导出链路。后续按以下顺序推进，每个条目单独开 PR。

## PR 1：基础架构

- Python 包、CLI、领域模型。
- 持久化浏览器会话接口。
- QQ 记事本列表和正文读取适配器。
- Word 单文件导出与批量编排。
- Windows CI、测试和文档。

验收：离线测试通过；真实登录可人工验证；不提交任何凭据。

## PR 2：登录稳定性

- 增加登录态检测的更多页面信号。
- 支持中文错误提示和重新登录引导。
- 增加浏览器启动诊断。

验收：`login` 在同时存在多个 `qq.com` Cookie 时仍能稳定找到有效 `sid`。

## PR 3：接口兼容性

- 保存脱敏后的响应样例。
- 补齐 `total`、空页、重复页和字段缺失测试。
- 增加速率限制退避策略。

验收：分页不会漏项或死循环；失效登录态有明确错误。

## PR 4：Word 保真度

- 支持表格、图片占位、链接和更完整的嵌套列表。
- 统一中文字体和段落间距。
- 增加标题重复、长标题和特殊字符快照测试。

验收：固定 HTML 样例生成的 Word 经人工检查无明显内容丢失。

## PR 5：断点续传

- 增加 `manifest.json`，记录笔记 ID、更新时间、输出路径和结果。
- 支持跳过已成功项和只重试失败项。
- 避免同一次运行重复覆盖。

验收：中途终止后再次运行只处理未完成笔记。

## PR 6：Windows 桌面界面

- 使用 PySide6 提供登录、选择目录、进度和错误列表。
- 保持核心层不依赖 GUI。
- 导出任务在后台线程运行，界面支持取消和重试。

验收：GUI 和 CLI 复用同一 `ExportService`。

当前实现状态：基础桌面窗口、登录、导出、进度和失败日志已完成；取消与重试仍在后续迭代。

## PR 7：Windows 打包与安装包

- 使用 PyInstaller 生成 `QQ记事本导出工具` 发布目录。
- 使用 Inno Setup 或 MSIX 生成安装包。
- 增加图标、版本信息、卸载和首次运行说明。

验收：全新 Windows 11 机器无需安装 Python，可双击安装、登录并导出 Word。

当前实现状态：PyInstaller spec、版本信息、单目录构建脚本、Inno Setup 脚本和发布目录
隐私扫描已完成；仍需在干净的 Windows 11 环境做安装与登录验收。
